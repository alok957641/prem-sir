# Wedding image assets

Keep these files in `public/images/`; the page references them by absolute `/images/...` paths.

- `cover-background.png`: animated opening-cover background
- `hero-couple-background.png`: full-screen landing hero background
- `toran.png`: fixed floral header toran
- `prem-portrait.png`, `nisha-portrait.png`: couple profile portraits
- `puja-ceremony.png`, `haldi-mehendi.png`: ceremony/event cards
- `reception-banquet.png`: venue and reception background
- `reception-stage.png`: reception artwork/card
- `wedding-mandap-ritual.png`: closing mandap image and RSVP background
- `wedding-couple-wide.png`, `wedding-couple-wide-alt.png`: family and gallery images
- `hero-mandap.png`: gallery background
- `prem-groom-editorial.png`, `nisha-bride-editorial.png`: alternate individual portraits
- `cover-temple.png`, `hero-mandap-soft.png`: alternate backgrounds
- `toran-transparent.png`, `toran-jasmine-marigold.png`, `toran-flower-hangings.png`, `toran-cream-garland.png`: alternate toran artwork

To replace any asset, keep its filename or update the corresponding `/images/...` path in `app/wedding-invitation.jsx` or `app/globals.css`.
